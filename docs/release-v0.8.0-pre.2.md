# v0.8.0-pre.2 — переход на лимитный Wi-Fi

Промежуточное исправление Android-клиента (versionCode 22), совместимое с сервером v0.8.0-pre.1. Сервер и wire-протокол не изменены; обновление серверного бинарника не требуется.

Когда VPN работает через LTE, появившийся Wi-Fi теперь проверяется как предпочтительный путь независимо от лимитности и настроек фонового резерва. После подтверждения доступности и выдержки против частых переключений клиент может перейти на него. Если путь пока не отвечает, рабочий LTE сохраняется и проверки повторяются с ограниченной задержкой. Правило применяется к обычным QUIC/HTTPS/AWG. Фоновое удержание LTE при работающем Wi-Fi остаётся под управлением настроек экономии.

Раньше выключенная настройка проверок лимитного Wi-Fi исключала его из автоматического возврата с LTE, хотя после ручного перезапуска VPN подключался через него. Подписи настроек уточнены: они относятся к фоновому резерву и не запрещают проверку предпочтительного Wi-Fi при работе через LTE.

## Проверки

- На pre.1 воспроизведён отказ: Android Wi-Fi помечен лимитным, режим выбранных приложений, VPN остаётся на LTE до таймаута теста.
- На pre.2 тот же переход Wi-Fi → LTE → лимитный Wi-Fi проходит с одним длительным TCP-соединением и неизменной VPN-сессией, включая короткую проверку при выключенном экране.
- Android APK/test APK и lint: успешно.
- Linux: go test -race ./mobile -run 'Test.*(Standby|Migration|Migrate)' -count=1 -timeout=180s — успешно. Включены существующие сценарии восстановления ответов холодного резервного пути; задержка интернета реальной магнитолы в лаборатории не воспроизводилась.

## Ограничения

Обрыв TCP в режиме всех приложений на проверенном Android/MIUI остаётся [ограничением первой фазы](post-phase1-backlog.md). Выбранные приложения — проверенный вариант. Системное завершение приложения с AutoLockOffClean этим выпуском не исправляется. Отдельный эксперимент с истечением bond UDP до hedge не включён в исправление. Новые функции группы C не входят в выпуск.

Серверные архивы: [v0.8.0-pre.1](https://github.com/vponomarev/quic-lab/releases/tag/v0.8.0-pre.1). Этот выпуск содержит новый APK и SHA256SUMS. APK подписан прежним ключом debug; обновление сохраняет профили.

Дополнительная проверка устройства: 14 обычных тестов прошли, один live-тест в этом запуске пропущен по явному opt-in (runner: 15). Затем live-проверки политики резерва отдельно прошли для QUIC, HTTPS и AWG на принудительно лимитном Wi-Fi, с выключенным разрешением фоновых проверок лимитного Wi-Fi. Проверены переход туда/обратно, удержание и освобождение LTE и смена состояния экрана. Системная настройка лимитности и пользовательский профиль восстановлены.
