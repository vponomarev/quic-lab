# Проверка резервной сети VPN

VPN / Exit node → Резервная сеть VPN. Настройки общие для всех профилей (включая multiple), применяются без перезапуска.

| Резерв / направление | Экран включён | Экран выключен |
|---|---|---|
| Wi-Fi / LTE → Wi-Fi | Включено | Включено |
| LTE / Wi-Fi → LTE | Выключено | Выключено |

Лимитный Wi-Fi и Wi-Fi с неизвестной стоимостью не проверяются без отдельного разрешения. Учитывается NOT_METERED Android.
Отключённый резерв LTE не запрашивается и не прогревается; пассивное наблюдение остаётся. При отказе основного пути мобильная сеть запрашивается для восстановления: это не запрет мобильных данных вообще.
При отключении проверки подготовленный резервный QUIC-путь удаляется. Текущий активный канал не закрывается.

QUIC проверяет путь к серверу, HTTPS — TLS с проверкой сертификата VPN-сервера через выбранную сеть. Автовозврат на Wi-Fi также требует системной валидации, выдержки времени и подходящей задержки. Неудачные проверки используют существующий backoff.
AWG не создаёт второго туннеля с тем же ключом, поскольку он перехватил бы обратный трафик. Используется системная валидация Wi-Fi; достижимость AWG endpoint подтверждается после переключения и при отказе работает recovery. Валидация Android не гарантирует доступность конкретного AWG endpoint.

RTT активного канала независим. Echo сохраняет поведение активной лаборатории, но незапущенный Echo больше не удерживает LTE только из-за открытия главного экрана.

## Проверка

Android instrumentation: VpnReserveTest, параметры vpn_reserve=true и transport=quic/https/awg. Тест временно меняет состояние экрана и Wi-Fi; сохраняет и восстанавливает настройки и профиль, останавливает VPN после проверки. Проверяет реальные REQUEST Android (отдельно от пассивных LISTEN), применение переключателей на лету, освобождение LTE и восстановление Wi-Fi → LTE → Wi-Fi. Проверка политики лимитности отдельная; реальный captive portal требует сети с порталом. Multiple использует тот же VpnSession, но одновременные профили на устройстве в этом тесте не проверяются.
