# Задачи после первой фазы MVP

## POST-P1-01 — обрыв соединений при возврате Wi-Fi в режиме «все приложения»

- Статус: отложено за пределы первой фазы MVP по решению владельца от 2026-10-01. Не блокирует её приёмку; срок и включение во вторую фазу отдельно не согласованы.
- Воспроизведение: на проверенном Android/MIUI включить обычный QUIC VPN для всех приложений, открыть длительное TCP-соединение, перейти Wi-Fi → LTE → Wi-Fi. При возврате Wi-Fi TCP-соединения приложений обрываются, хотя VPN-сессия сохраняется; обрыв предшествует миграции QUIC. На других устройствах и транспортах этот эффект пока не подтверждён.
- Доказательства: текущий pre.1 и старый APK 0.7.4 с нынешним профилем/сервером воспроизводят обрыв. Режим «выбранные приложения» на pre.1 прошёл два автоматических теста; владелец подтвердил исправную работу переключения в Brawl Stars после восстановления этого режима.
- Диагностический эксперимент: исключение системного UID1000 из VPN дважды устранило обрыв. Точная причина внутри Android/MIUI пока не установлена. Такое исключение не включать молча: оно отправляет системный трафик напрямую.
- Работа: установить механизм закрытия сокетов при захвате системного трафика; найти решение либо явно настраиваемый обход с описанием маршрутизации; проверить применимость на других Android/прошивках и транспортах.
- Критерии готовности: длительные TCP-соединения и UDP-потоки переживают повторные Wi-Fi → LTE → Wi-Fi в режиме всех приложений; нет скрытого прямого обхода VPN, регрессии выбранных приложений и блокировки назначенного VPN-трафика. Любые необходимые системные исключения согласованы и видимы пользователю.

Ограничение первой фазы закреплено в [спецификации](superpowers/specs/2026-09-30-vpn-product-design.md#ограничение-первой-фазы-androidmiui) и [статусе разработки](phase1-progress.md). Отдельный дефект задержанного hedge в bond UDP этой задачей не переносится за пределы первой фазы.
