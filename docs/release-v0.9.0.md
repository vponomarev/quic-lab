# QUIC Lab 0.9.0

0.9.0 завершает первую фазу продукта по пересмотренному владельцем объёму приёмки.

## Состав

- Android 0.9.0, versionCode 40; существующая подпись APK сохранена.
- Собственные QUIC/HTTPS, мультиплексор и поддержка AWG/VLESS в текущем объёме.
- Обновление настроек зарегистрированного устройства с сохранением идентичности и локальных правил.
- Клиентская диагностика на сервере, навигация по пользователю/устройству и сведения о версии приложения.
- Улучшения Android UI и админки, обновлений APK, приглашений и отзыва устройств.
- LTE-счётчик сохраняется между аварийными перезапусками: восстанавливается последняя запись с допускаемой погрешностью. Явный Stop начинает новый период.
- При открытии приложения после гибели процесса восстанавливается прерванный VPN в пределах той же загрузки Android. Неуспешный запуск не создаёт бесконечный автоповтор.

## Известные ограничения

- Дорожное QUIC-зависание при видимом живом RTT ещё не объяснено; перезапуск VPN помогал пользователю.
- Отдельный opt-in эксперимент с уменьшением MTU без смены адреса воспроизводит остановку передачи; он не доказан причиной дорожного случая.
- MIUI может не восстановить процесс в фоне даже при START_STICKY. Восстановление при открытии проверено; универсальное unattended-восстановление не обещается.
- На проверенном Android/MIUI режим всех приложений может разрывать соединения при возврате Wi-Fi; режим выбранных приложений служит принятой альтернативой.
- Строгая защита от намеренного обхода исключений приложениями остаётся задачей фазы 2.
- Полная матрица переключений/отказов, расширенная совместимость VLESS/Echo, нагрузка и свежий восьмичасовой прогон 0.9 перенесены в фазу 2. Перенос не означает успешную проверку.

Непосредственно после 0.9 начинается MDM core: добровольная привязка, права, независимое управление, два режима конфигурации, команды VPN и аудит. Телеметрия/remote helper продолжают этот этап; в 0.9 они не реализованы. Исследовательский режим также пока существует только в документах.

## Артефакты и обновление

GitHub содержит APK, Linux amd64/arm64 server archives, исходники и SHA256SUMS. ARM64 собирается перекрёстно; runtime-проверки выполняются на amd64.
Данные пользователей, ключи, production-конфиги и персональные диагностические журналы не входят в исходники/артефакты.
Обновление сервера перезапускает соединения. Существующие настройки, включая разрешённый для Web UI TLS 1.0, сохраняются.
Подробности фактической регрессии и публикации: release-v0.9.0-regression.md.
