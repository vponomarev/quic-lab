# RTT VPN и состояние экрана

В Android: **VPN / Exit node → Диагностика**. Настройки общие для всех профилей, включая multiple:

| Состояние экрана | По умолчанию | Варианты |
| --- | --- | --- |
| Включён | Раз в секунду | Выключено / 1 с / 5 с |
| Выключен | Выключено | Выключено / 1 с / 5 с |

Изменения применяются к работающему VPN без его перезапуска, в том числе при переключении состояния экрана. Определяется интерактивность устройства через PowerManager.isInteractive: разблокировка не требуется, always-on display не считается активным экраном. Смена профиля и импорт QR не сбрасывают общие настройки RTT.

Настройка управляет измерениями до VPN-шлюза и транзитного узла. При отключении RTT интерфейс показывает «выключен», скрывает старые значения и не строит график по служебным ответам. В multiple каждый профиль сохраняет свой статус связи.

Echo, в том числе публичный AWG Echo и Echo по профилю, сохраняет свой режим измерений: настройки VPN на него не действуют.

Отключение RTT не означает отсутствие служебных пакетов. Проверка связи остаётся раз в 5 секунд (для AWG — ICMP через туннель). Она выдаёт событие health без RTT и jitter. При отсутствии ответов порог восстановления учитывает этот интервал; сетевые callbacks и ошибки транспорта продолжают обрабатываться сразу. Частоту поддержания транспорта, проверки резервного пути и exit IP этот параметр не меняет. Поэтому это частичное уменьшение диагностической нагрузки, не полный режим энергосбережения.

Проверка на устройстве: выбрать разные режимы для двух состояний, запустить VPN, погасить экран и убедиться по событиям rtt_policy и частоте обмена в применении настройки. Проверить возврат измерений, отсутствие ложных переподключений после 30 секунд покоя, WiFi/LTE, QUIC/HTTPS/AWG и multiple. Отдельно проверить Echo. Экранные события не отменяют системные ограничения Doze.

Проверки резервной сети настраиваются независимо: [направления LTE / Wi-Fi и лимитные сети](vpn-reserve.md).
