Обновление настроек профиля и повторный показ приглашений.

- Android: у зарегистрированного подключения в списке есть «Обновить настройки». Открывается проверка изменений, применение — только после подтверждения. Используются прежние ID и ключи устройства; локальные приложения, маршруты и экономия сохраняются.
- Админка: новые действующие приглашения поддерживают «Показать QR» и «Копировать ссылку». Срок и лимит не меняются. Старые приглашения с одним хешем восстановить нельзя; автоматического перевыпуска нет.
- Токен нового приглашения сохраняется зашифрованно, выдаётся только авторизованному администратору по запросу с CSRF. Отзыв удаляет сохранённый ciphertext.
- Раздача приглашения из Android записана в POST-P1-05 после фазы 1, без дочерних приглашений.

Проверки: Linux admin/server tests, enrollment race и admin vet; браузерная проверка показа/копирования/очистки QR; Android build/lint и 13 instrumentation-тестов обновления профиля.
Android versionCode 37. Требуется совместное обновление сервера и APK для обеих функций.
