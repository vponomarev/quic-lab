# Библиотека профилей Windows

В настройках появилась вкладка **Профили**. Сначала сохраните первое подключение
обычной кнопкой «Сохранить». После этого библиотека доступна для настроенного
клиента. Нужна служба с возможностью `profile-library-v1`; со старой службой
обычный редактор работает, кнопки библиотеки отключены.

1. Заполните вкладку «Подключение» вручную или загрузите профиль/приглашение.
2. Во вкладке «Профили» нажмите **Сохранить как новый**. Сохраняются параметры
   редактора, работающий VPN не меняется. Для обновления снимка выберите его и
   нажмите **Заменить выбранный**, подтвердив замену.
3. Для переключения выберите снимок и нажмите **Выбрать профиль**. Несохранённые
   правки редактора требуют подтверждения замены; работающий VPN — подтверждения
   переподключения. При остановленном VPN выбор сам по себе его не запускает.
4. **Удалить** убирает только снимок из библиотеки. Уже выбранная конфигурация
   подключения остаётся сохранённой.

Профиль заменяет название, транспорт, адрес сервера, ключи и параметры доверия.
**Локальные подсети, режим захвата, DNS, физический интерфейс и правила приложений
сохраняются.** Получившееся сочетание проверяется заново: например, сервер внутри
захватываемой подсети или AWG AllowedIPs, не покрывающие текущие подсети, приводят
к отказу до остановки старого подключения.

Снимки независимы: обычное редактирование активного подключения не обновляет
библиотеку автоматически. Если новый сервер не подключился после сохранения,
выбранные параметры остаются сохранёнными. Для ручного отката выберите прежний
снимок; автоматического отката и нескольких одновременно работающих VPN здесь нет.
Явное переключение завершает открытые VPN/direct-соединения.

Служба хранит до **32 профилей**, суммарный JSON документа — до **1 МиБ** вместе
с активными настройками. Хранилище использует существующее DPAPI-шифрование и
атомарную замену файла. Списки IPC содержат только ID, название, транспорт и
адрес; ключи обратно в UI не выдаются. Общая ревизия защищает от перезаписи
другим окном. При конфликте или неизвестном результате ответа откройте настройки
заново перед повторением операции.

Старый документ без библиотеки загружается с пустым списком, активное подключение
сохраняется. Старый UI может редактировать активные настройки новой службы,
сохраняя библиотеку. **Обратная установка старой службы после сохранения
библиотеки не поддерживается:** прежний строгий reader не понимает поле
`profiles`. Не подменяйте файл хранилища вручную. Установленная служба этой
разработкой автоматически не заменяется.
