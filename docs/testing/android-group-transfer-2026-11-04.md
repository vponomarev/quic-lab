# Перенос и MDM-конфигурация Android-групп — 2026-11-04

Продолжение после `6d15055`, в `.worktrees/phase1-vpn`, ветка `codex/windows-client-beta`. Закрыт блок переноса явного состава автоматических групп и связанных ссылок. Схема конфигурации остаётся версии 1; поддержка согласуется capability `automatic_groups_v1`.

## Реализованное поведение

- Состав группы сохраняется в локальном снимке, зашифрованном экспорте, импорте и откате. Добавление, обновление и замена явно переназначают ID участников и общего выхода. Даже совпадающий ID назначения не считается разрешением автоматически привязать чужой профиль.
- При частичном экспорте интерфейс запрашивает сопоставление внешних участников и relay-выхода. Предпросмотр показывает состав именами подключений; добавление ранее отсутствовавшего поля не вызывает NPE.
- Валидатор отклоняет отсутствующие, повторные и собственные ссылки, вложенные группы и пересечение включённых multiple-выходов. Удаление используемого профиля требует сначала убрать ссылки на него.
- Сервер принимает и выдаёт группы только поддерживающим клиентам, включая повторную проверку после downgrade. Android объявляет capability и учитывает ответ сервера.
- Старый сервер получает совместимый снимок без поля состава; обратное применение режима current сохраняет локальный состав. Удаление участника таким обновлением отклоняется до остановки VPN. Непредставимая для старого сервера смешанная HA-конфигурация не отправляется как ложный самостоятельный профиль: опускается configuration, остальные разделы отчёта сохраняются. External-конфигурация остаётся независимой от личного состава.
- Управляемый текущий, включённый или разрешённый для выбора корень может использовать явно объявленного участника/общий выход. Это не даёт участнику права самостоятельного выбора.
- При импорте проверяются ключи итогового runtime, включая ранее существовавших участников. Если активному выходу, его зависимостям или tunnel DNS не хватает ключей, автоматическое возобновление VPN запрещено; неполный конфиг остаётся доступным для исправления.
- До остановки VPN и записи проверяется лимит 16 логических подключений с учётом реально сохранившейся подписки назначения. Перенос 17 отдельных узлов одной подписки с новыми ID теряет приватную принадлежность и теперь отклоняется; исходная работающая конфигурация сохраняется. Лимиты 32 физических профиля / 4096 кандидатов не увеличены.

## Решения и остаток

- Выполнение продолжено автономно по разрешению пользователя, в существующей изолированной рабочей копии. Ветка и рабочая копия сохраняются для просмотра; дополнительного меню интеграции не требуется.
- Сохранены schema1 и явное сопоставление ID. Старый импортёр отклоняет неизвестное поле; управление группами через MDM требует обновления сервера и клиента. Старый сервер не может редактировать состав группы.
- URL подписок, токены обновления и приватная принадлежность подписке не стали переносимыми метаданными. Если перенос превращает одну подписку в более 16 независимых подключений, нужно предварительно собрать её узлы в один профиль группы. Полная переносимость подписок остаётся отдельным расширением.
- Работа ограничена группами, ссылками и безопасностью применения; общая проверка всех исторических ключей, полная физическая Wi-Fi/LTE/Doze/OEM-матрица, длительный soak, QUIC MTU/MIUI, тихий MDM и RemoteHelper этим блоком не закрываются. Предыдущая проверка реального QUIC→HTTPS переключения без TUN описана отдельно в `android-group-stability-2026-11-04.md`.
