# Удалённая диагностика Wi-Fi/LTE и агрегат — 2026-11-04

База `eea0f15`, ветка `codex/windows-client-beta`, worktree `.worktrees/phase1-vpn`. Продолжение плана adaptive paths: агрегированный каталог MDM, удалённая последовательность фаз и управление ей в WEB. Серверные изменения ещё не развёрнуты.

## Реализовано

- Каталог MDM включает «Все VLESS-источники» при поддержке фаз и общем размере 1..256 узлов. Агрегату выделяется одно из 32 мест; до 31 места остаются отдельным источникам. Если агрегат превышает предел, он отсутствует целиком. Fingerprint учитывает всех участников; старый сервер получает прежний каталог.
- Отдельная кнопка «Wi-Fi / LTE» отправляет `mode=phased`; старый запуск «Текущая сеть» сохраняет поведение. Новый command kind `vless_probe_sequence` согласован через `vless_probe_sequence_v2`. Retry/cancel выбирают режим по схеме результата и требуют точного run/source/fingerprint.
- Каждая синхронизация Android объявляет поддержку нового kind. Сервер проверяет и текущий запрос, и сохранённый отчёт: откат APK не блокирует MDM незнакомыми командами до обновления отчёта. Прежний сервер игнорирует дополнительное sync-поле через существующий `json.Unmarshal`; native transport проверяет валидность JSON, не ограничивая его поля. Старые wire-данные отчётов не расширяются без согласования.
- Удалённая последовательность использует существующие сетевые leases и движок: Wi-Fi, затем разрешённый LTE; при старте на LTE — только LTE. Действуют прежние лимиты 2 workers, 256 узлов, 45 минут, разрешение резервного LTE и общий бюджет.
- Binding/epoch/consent generation и права VPN+telemetry проверяются до/после получения сети, между фазами, перед работой, после DNS и создания native probe. Отзыв прекращает последовательность; lease закрывается после завершения работников. Quiet MDM отклоняет start/retry, сохраняя разрешённую отмену.
- Отчёты удалённых schema2 принимаются только с соответствующей start/retry-командой того же kind/source/fingerprint/epoch. Cancel не создаёт основание для нового результата. Смена эпохи прерывает вложенные незавершённые фазы. Публичная проекция и лимиты 768/900 КиБ остаются прежними.

## Независимое ревью и исправления

Один свежий рецензент проверил весь пакет относительно базы. Critical не найдено. Два Important/P2 исправлены одним проходом:

1. Повтор retry с прежним request ID после нового результата ошибочно возвращал conflict. Кэш идемпотентности теперь проверяется до изменяемого target snapshot, после прав/capabilities/источника. `TestProbeSequenceRetryIdempotencyAfterNewSnapshot`: `idempotency-red.log` → `idempotency-green.log`.
2. При откате APK сервер доверял старому отчёту возможностей, а старый Android сначала выполнял sync и отвергал новый kind, не успевая обновить отчёт. Добавлено согласование в каждом запросе. `TestProbeSequenceSyncNegotiatesBeforeDowngradeReport`: `downgrade-red.log` → `downgrade-green.log`; Kotlin `everyPollAdvertisesSequenceParserCapability`: воспроизведение `No value for capabilities` в `downgrade-device-red.log`, затем итоговая регрессия. Проверены отсутствие поля, чужая capability, новый клиент и доступность legacy-команд.

Повторное ревью не запрашивалось: воспроизведения и полная регрессия проверяют исправления. Первый запуск Android RED был сделан до завершения сборки и обнаружил 0 тестов; он не считается доказательством. После завершения сборки новый test APK установлен повторно, тест запущен и ожидаемо упал.

## Решения, отложенное и границы

- Автономное выполнение, PowerShell-команды с сохранёнными журналами вместо shell helpers; существующая локальная ветка/worktree сохраняются. Цена: интеграция и развёртывание остаются последующими действиями.
- Текущий sync обязан подтвердить parser capability. Сохранённого отчёта недостаточно; команды без текущего согласования ждут обычного TTL. Цена: клиент, объявляющий поддержку только в отчёте, не получит новый kind, но обычный sync продолжится.
- Физические Wi-Fi/LTE, OEM/Doze, расход батареи и моментальное прерывание native-вызовов рецензент не оценивал. Основной исполнитель проверял синтетические lease/ownership сценарии, native-тесты и Note9-регрессию; это не физическая приёмка. Цена: указанные сценарии остаются обязательными перед выпуском.
- Minor, отложено: тест каталога подаёт 33 источника напрямую, а production enumeration ограничивает список ранее. Поддерживаемые пути создания/валидации ограничены 32 профилями и 256 узлами; недостижимость усечения зависит от этих инвариантов. Отдельный интеграционный тест этой границы пока не добавлен.
- Go mobile/AAR не менялся. Реальные VPN/MDM/радио/подписки и права пользователя не запускались и не менялись. Сервер не развёрнут, push/merge не выполнялись; посторонние cell/admin/server изменения сохранены вне пакета.
