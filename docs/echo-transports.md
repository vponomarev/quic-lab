# Echo: три транспорта и транзитный RTT

Обычный публичный Echo продолжает работать по QUIC и HTTPS/WebSocket.
Для сравнения с AmneziaWG выберите импортированный VPN-профиль, затем на главной
странице включите «Echo через VPN-профиль» и нажмите Start Echo. Используются
доступные протоколы этого профиля; для всех трёх нужны соответствующие права
на сервере и AWG-конфигурация. Публичный QR Echo не содержит ключей AWG.

Приложение открывает независимые аутентифицированные подключения к VPN-портам,
но не создаёт системный VPN/TUN и не меняет маршруты других приложений.
Одновременно запускать обычный VPN и этот опыт нельзя. Параллельное использование
того же AWG-ключа на другом устройстве может вызвать roaming между устройствами;
для опыта используйте отдельный клиентский профиль.

Каждая карточка показывает `RTT шлюз / транзит`, если профиль содержит
transit_endpoint. Обе величины измеряются от телефона:

- шлюз: до точки терминации первого VPN;
- транзит: через первый VPN до удалённого gateway из конфигурации аплинка.

Вторая величина — полный RTT, первый участок из неё не вычитается. Это задержка
до удалённого gateway, а не до произвольного сайта после него. График и jitter
показывают первый RTT. Отсутствие свежего ответа обозначается прочерком.

QUIC/HTTPS используют прикладной echo/keep-alive (10 запросов/с), AWG — ICMP
через туннель (1 запрос/с). Транзитная проба — примерно раз в секунду. Из-за разной
частоты и вида проб jitter/паузы не являются строго эквивалентным бенчмарком.
Для AWG показывается число ICMP-проб, а не выдуманный ID серверного сеанса.
ICMP может фильтроваться — отсутствие ответа само по себе не означает поломку VPN.

Серверная часть уже поддерживает эти пробы; новые публичные порты не нужны.
Opt-in тест на Android: ProfileEchoTest с `-e profile_echo true`; выбранный профиль
должен разрешать все три транспорта. Проверка требует реального устройства и
работающих серверов; результат установки/прогона фиксируется отдельно.

Статус проверки: APK и instrumentation APK собраны, Android lint прошёл.
На Android 12 установлен APK и пройден ProfileEchoTest: все три транспорта
получили локальный echo и полный транзитный RTT; системный VPN не запускался.
Визуальная проверка карточек пока ожидает разблокировки экрана телефона.


## Публичный Echo без VPN-профиля

В конфигурации admin.json задайте отдельный endpoint, например:

```json
"echo_awg": "lab.example.org:51821"
```

Откройте UDP 51821 на сервере и перезапустите quic-lab. Порт должен отличаться
от обычного AWG VPN и остальных UDP listeners. Публичный QR на странице лабы
автоматически получит `awg_enroll_url`. Сканирование нового QR и Start Echo
запускают QUIC / HTTPS / AWG без логина, клиентского сертификата или VPN-профиля.
Старый QR следует пересканировать. Обычные QUIC/HTTPS остаются совместимыми.

AWG использует автоматическую выдачу временного peer через HTTPS. Ключи живут
только в памяти сервера/клиента, не создают пользователя в админке и истекают
через 10 минут. Для нового опыта нажмите Stop/Start Echo. Максимум 64 активных
peer и 32 выдачи в минуту на сервер. При перезапуске сервера временные peer
теряются; обычные VPN-пользователи хранятся отдельно.

Userspace AWG Echo не создаёт Linux TUN и не использует host forwarding/NAT.
Его внутренняя сеть существует только в userspace-стеке. Разрешены ICMP к
внутреннему адресу Echo и UDP-проба с фиксированным назначением — настроенным
транзитным gateway. Произвольные TCP/UDP назначения и доступ к LAN отсутствуют.
Клиент не может расширить доступ изменением AllowedIPs.

При включённом транзите все три публичных транспорта показывают полный RTT
до удалённого gateway. Пробы QUIC/HTTPS выполняются асинхронно, не задерживая
обычный Echo; число параллельных транзитных проб ограничено.

Проверены на Linux: настоящий AWG handshake, локальный и транзитный Echo,
изоляция при изменённых клиентом AllowedIPs, истечение peer, лимит выдачи,
отсутствие блокировки локального Echo медленной транзитной пробой (race tests).
На живом сервере проверены оба RTT публичных AWG/QUIC/HTTPS.

На Android 12 также пройден PublicEchoTest#anonymousAwgSession: автоматическая
публичная выдача peer, локальный/транзитный RTT без VPN-профиля и VpnService.
UI-проверка публичных трёх карточек ожидает разблокировки экрана.
