Версии клиента в диагностике и уведомление об обновлении.

- Каждое новое диагностическое событие содержит versionName и versionCode; старая история остаётся без версии.
- Админка показывает последнюю известную версию устройства и сводку по версиям.
- Android проверяет версии на серверах зарегистрированных профилей при открытии приложения (не чаще раза в час) и вручную.
- Кнопка «Обновить» в шапке ведёт в настройки; APK скачивается через браузер.
- Серверные capabilities дополнены android_version_name и android_version_code. Обязательный минимум версии не меняется.

Проверено: go test ./internal/admin ./internal/protocol ./cmd/server; браузерная регрессия админки; APK + lint; на Redmi — 7 выполненных Android-тестов, 2 opt-in теста пропущены. Проверены миграция SQLite и переход кнопки обновления. Старый профиль Redmi без регистрации устройства не получает версию с сервера.
