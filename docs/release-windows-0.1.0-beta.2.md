# QUIC Lab Windows 0.1.0-beta.2

Первый выпуск с обычным **Setup.exe** для Windows 10/11 x64. Скачайте `quic-lab-windows-0.1.0-beta.2-x64-setup.exe`, запустите двойным щелчком и подтвердите запрос прав администратора. Распаковывать архив, вводить SID, устанавливать .NET или заранее создавать engine.json больше не нужно.

## Первый запуск

1. После установки запустите **QUIC Lab** из меню «Пуск».
2. Нажмите **Настроить подключение**.
3. Загрузите HTTPS-ссылку-приглашение/профиль в настройках либо введите параметры своего сервера. Для AWG и VLESS доступны соответствующие поля импорта.
4. Сохраните настройки и нажмите **Подключить**.

Для нового профиля выбраны весь IPv4 и автоматический выбор физической сети. Профили и приватные ключи в установщик не входят. VPN после установки и обновления выключен. Закрытие окна не отключает VPN — используйте кнопку «Отключить».

Установка сохраняет прежнее расположение `C:\Program Files\QUIC Lab Windows Preview` и имя службы `QuicLabWindowsPreview`. Владелец нового подключения определяется по текущему сеансу Windows, даже если в UAC введены данные другого администратора. При обновлении существующий владелец и защищённые настройки сохраняются. Установщик отказывается принимать чужую регистрацию службы, ссылки/junctions и каталоги с небезопасными правами.

Удаление доступно в **Параметры Windows → Приложения**. Оно останавливает и удаляет службу и программу; приватные настройки в ProgramData сохраняются для повторной установки. Подтверждение отмены удаления не затрагивает службу. DPAPI-файлы между компьютерами не переносите.

## Проверки и границы

Проверены регрессии Go Windows service/engine, пустое и повреждённое хранилище, первый save/restart, сериализация первого профиля, WPF dashboard/settings/import, проверки владельца службы, прав и целостности пакета в Windows PowerShell 5.1, определение пользователя сеанса, сборка Inno Setup. Wintun имеет действительную подпись WireGuard, .NET runtime включён.

Полный цикл установки/обновления/удаления с повышенными правами и UAC другого администратора пока не прошёл отдельную аппаратную приёмку. Существующий установленный QUIC-клиент проверен 2026-10-28: HTTPS, DNS TCP/UDP, ICMP, счётчики и очистка ограниченного маршрута; это не приёмка нового установщика на чистом ноутбуке. Windows 11, физическое переключение Wi-Fi/LTE и sleep/resume остаются отдельными проверками.

Сохраняются ограничения beta: IPv6 вне VPN, нет kill switch и маршрутизации по приложениям; одно сохранённое подключение. Собственный Setup.exe и EXE приложения пока не имеют Authenticode-подписи. Контрольные суммы опубликованы в `SHA256SUMS.txt`. Исходники — тег `windows-v0.1.0-beta.2`.
