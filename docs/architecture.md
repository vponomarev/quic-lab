# Устройство приложения

QUIC использует один надёжный двунаправленный stream и NDJSON echo. WSS передаёт
тот же протокол через HTTP/1.1/TLS/TCP. Сервер выдаёт случайный прикладной ID для
каждого нового соединения; этот ID не равен wire QUIC connection ID.

Kotlin запрашивает Wi-Fi и cellular через ConnectivityManager.requestNetwork,
привязывает сокеты к Android Network до connect и сериализует миграции.
QUIC заранее проверяет резерв, повторяет проверки на сохранённом сокете/CID,
держит не более двух кандидатов плюс активный транспорт. onLost удаляет путь,
Stop освобождает ресурсы. После окончательного закрытия нужен новый запуск.

Возврат на Wi-Fi защищён выдержкой стабильности. WSS следует за выбором QUIC,
но также самостоятельно восстанавливается при onLost и возвращается на Wi-Fi:
после 5 секунд VALIDATED и минимум 8 секунд на текущем канале сначала проверяет
TLS/WebSocket, сохраняя рабочее сотовое соединение до успеха. Ошибка Wi-Fi
откладывает следующую попытку на 15 секунд. TLS session resumption разрешено.

Сервер: QUIC UDP/4433, WSS backend loopback TCP/8081, TLS/WSS proxy nginx TCP/443.
Поэтому опыт показывает сохранение сеанса и восстановление приложения, а не
универсальный бенчмарк транспорта. QUIC миграция не гарантирует отсутствие пауз.

RTT вычисляется монотонными часами Go. Пауза учитывает reconnect по Android
elapsedRealtime. Jitter — максимум |RTT[i]−RTT[i−1]| внутри окна 15 секунд;
пропадание ответов не прибавляется к RTT jitter. Stop фиксирует окно.

Радиосведения используются локально: SSID/BSSID, RSSI, доступные параметры
обслуживающей соты и возраст измерения. Android может скрыть или задержать их.
Вертикальные отметки отражают обнаружение события приложением, а не точный
момент радиохэндовера. Нужна foreground точная геопозиция; background location
не запрашивается. Приложение следует держать открытым во время опыта.

В fork quic-go исправлены маршрутизация PATH_RESPONSE, управление probing CID,
повторные проверки, удаление старых transport и поведение при потере probe.
Подробности и полный diff: `third_party/README.md`, `migration-fixes.patch`.
