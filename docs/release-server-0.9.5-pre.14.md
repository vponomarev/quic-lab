# Server 0.9.5-pre.14 — восстановление карты MDM

Восстановлена карта приблизительных мест наблюдений по сотовым станциям,
пропавшая после обновления сервера до pre.13. Ранее развёрнутая реализация
оставалась в незакоммиченном рабочем каталоге и не попала в сборку pre.13.

- Карта на странице истории Wi-Fi/сот, период до 7 суток, шкала времени,
  радиус оценки, источник и история координат выбранной соты.
- Постоянная SQLite-база, кэш отрицательных результатов и фоновая очередь.
  Существующая база совместима; повторное сканирование не требуется.
- Выбранные даты сохраняются после перезагрузки и кнопки «Обновить».
- SQLite входит в полные резервные копии; восстановление проверяет целостность,
  поддерживаемую версию и обязательные поля базы до замены рабочих данных.
- Регрессионный тест проверяет наличие карты и всех её ресурсов в сервере.

Путь: устройство MDM → история Wi-Fi/сот → «Точки по сотовым станциям» →
«Показать точки». Если точки появились после фоновой обработки, «Все точки»
подбирает масштаб. Координаты приблизительные, GPS не используется.

Серверные архивы: Linux amd64 и arm64. Android остаётся 0.9.5-pre.13/code78;
переустановка приложения для этого исправления не нужна. MDM-редактор и
серверные exits из pre.13 сохранены. Проверки и развёртывание:
[приёмка](testing/cell-map-restore-2026-11-09.md).
