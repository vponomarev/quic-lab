# Разделение путей, общей сессии и выхода

## Слои
1. Android TUN и маршрутизация приложений/подсетей.
2. Session / multiplexer: стабильные потоки, подтверждения, дедупликация, планировщик, бюджеты. Пакет internal/bond не зависит от QUIC, AWG, HTTP или Android.
3. Защищённый канал до сервера объединения. Первый адаптер internal/bondquic использует mTLS QUIC DATAGRAM. Его контроль перегрузки ограничивает отправку на каждом пути; независимые ограниченные очереди не позволяют медленному пути заблокировать соседний.
4. Доступ к серверу объединения (underlay): напрямую через Wi-Fi/LTE либо через встроенный VPN/прокси. Для AWG нужны отдельные peer/ключи на независимых путях; внешние Android VpnService не могут быть основой двух одновременных путей.
5. Сервер объединения: один реестр сессий и один набор TCP-соединений / UDP-сопоставлений к конечным адресатам.

## Развёртывание
Встроенный сервер QUIC Lab и отдельный demultiplexer должны использовать одинаковые Session и gateway. Внешним VPN не требуется понимать наш протокол: они доставляют зашифрованный обмен до demultiplexer. Выходной IP конечного трафика принадлежит demultiplexer (или его настроенному транзиту), а не внешнему промежуточному VPN.

Сквозная аутентификация до demultiplexer обязательна даже внутри стороннего VPN. Владение внешним VPN не даёт права присоединения к общей сессии. Сервер выбирает пути для ответов; клиент выбирает пути для исходящего трафика. Ни одна сторона не может единолично контролировать доставку в обоих направлениях.

## Возможности адаптера
Адаптер обязан предоставлять аутентифицированные сообщения с границами, ограниченными очередями, отменой и контролем перегрузки. QUIC предоставляет DATAGRAM непосредственно. TCP-only proxy требует отдельного защищённого потокового адаптера: внутри одного пути останется HoL, но соседний путь независим. UDP-адаптер AWG или Xray должен сохранять границы сообщений. Эти адаптеры не должны менять идентификаторы потоков или управлять повторным открытием конечных TCP-соединений.

## Текущий этап
Реализуется прямой QUIC + QUIC, сервер объединения встроен в gateway. Реестр и обработчики потоков не зависят от веб-админки/Echo. Отдельный исполняемый demultiplexer добавлен в cmd/demux. Импорт внешних профилей, AWG underlay и Xray — следующие адаптеры, не скрытая эмуляция двумя независимыми пользовательскими VPN-сессиями.
