# Linux GUI: управление готовыми подключениями

Пользователь выбрал первый этап без редактирования: запуск/остановка VPN,
выбор существующего профиля, состояние, трафик, понятные сообщения ошибок.
Сохраняется ранее данное поручение работать автономно. Проверка на ноутбуке
и установка выполняются при доступности 192.168.5.149; исходники проверяются
на разрешённом тестовом хосте без передачи пользовательских профилей.

Выбранное исполнителем решение: Python 3 + GTK 3/PyGObject, обычное окно
пользователя и отдельный root systemd control service с Unix socket.
Альтернативы: локальная веб-панель требует браузера и защиты HTTP;
новое кроссплатформенное GUI-ядро увеличивает зависимости первой версии.
GTK подходит для Ubuntu ноутбука и не требует изменения Go VPN-ядра.

Окно: статус службы/готовность транспорта (без обещания доступности интернета),
четыре готовых профиля QUIC/HTTPS/AWG/VLESS, подключить/отключить,
переподключить, автозапуск VPN при загрузке, суммарный трафик и скорость,
очищенная история событий. Переключение работающего профиля сопровождается
подтверждением разрыва соединений. Закрытие окна не меняет VPN. Выбор в combo
до нажатия кнопки не меняет профиль. Локальные ошибки связи не показывают
ложное состояние «отключён». Нет редактора, импорта, новых route/DNS настроек,
MDM, tray и смены физической сети в этой итерации.

Сервис ограничен одной существующей службой quic-lab-client и четырьмя
root-owned 0600 файлами /etc/quic-lab/profiles/{quic,https,awg,vless}.json.
Доступ: root и один UID, записанный администратором в root-owned конфигурацию.
Обе стороны проверяют SO_PEERCRED; клиент требует root сервер.
API не принимает путь, команду shell, JSON профиля или имя systemd unit.
Ссылка client.json заменяется атомарно после проверки профиля существующим
CLI -validate. При неудаче запуска восстанавливается прежняя ссылка;
профиль/служба неизвестной структуры не заменяется молча. Операции
сериализуются, ожидания ограничены. Status отдаёт только публичные метаданные,
числовые counters и известные категории событий; ключи/сырой журнал не выдаются.
Каждая выборка привязана к текущему InvocationID, чтобы не показать старый трафик.

Установщик добавляет GUI, launcher и отдельный control service, не заменяет
VPN бинарник, network helper, unit VPN или приватные профили. Разрешённый UID
получает только управление VPN/автозапуском; uninstall убирает именно GUI.
Ограничение: локальные процессы этого UID имеют те же права управления.

Приёмка: тесты API/авторизации/rollback/санитизации; GUI без root в Xvfb;
реальный service smoke на отдельном стенде; на ноутбуке запуск окна, connect,
disconnect, выбор профиля, сохранение VPN после закрытия; QUIC оставить enabled.
Недоступность ноутбука не заменяет физическую приёмку стендовым тестом.
