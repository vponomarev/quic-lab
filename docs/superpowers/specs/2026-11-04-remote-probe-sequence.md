# Удалённая последовательная диагностика и агрегат

База eea0f15, продолжение согласованного adaptive paths. Пользователь поручил автономную реализацию; существующий Kotlin/Go/JobScheduler стек сохраняется. Пакет закрывает агрегированный источник и новые remote-команды поверх уже передаваемой schema2.

Выбор исполнителя: отдельная capability `vless_probe_sequence_v2` и kind `vless_probe_sequence`, request mode=`phased`. Расширение прежнего kind с неявной трактовкой старым клиентом исключено; отдельный движок тоже исключён из-за дублирования владения сетью. Прежний start остаётся одно-сетевым. WEB добавляет отдельный запуск «Wi-Fi / LTE»; retry/cancel выбирают протокол по схеме сохранённого запуска и capabilities.

Каждый sync-запрос нового APK объявляет `capabilities:["vless_probe_sequence_v2"]`. Сервер выдаёт новую команду только при поддержке и в текущем запросе, и в сохранённом отчёте. Отсутствие поля после отката APK немедленно исключает новые команды, даже до обновления отчёта; старые команды остаются доступны. Прежний сервер разбирает sync через json.Unmarshal и допускает это дополнительное поле. В очереди новые команды сохраняются до обычного TTL. Идемпотентный повтор retry возвращает исходную команду и после появления результата нового запуска, сохраняя проверки прав/capabilities/источника.

Агрегат создаётся из полного набора источников без усечения узлов, только при 1..256 узлах и поддержке сервером фаз. Он получает одно из 32 мест каталога; остаются до31 отдельных источников. Fingerprint и node IDs использует прежний allProbeSource. Изменение любого участника инвалидирует прежние результаты.

Remote v2 использует VlessProbeSequence: Wi-Fi затем разрешённый LTE, при старте LTE только LTE. Начальное получение сети, граница фаз и каждый worker перепроверяют активную привязку, epoch, consent generation и VPN+telemetry. Отзыв отменяет всю последовательность; resource lease закрывается после drain. Согласие на резерв LTE и общий бюджет проверяются прежними механизмами, отсутствие сети/запрет не считаются отказом узла. Quiet MDM не запускает длительную диагностику; cancel остаётся доступным с правами.

Run ID равен command ID, owner metadata остаётся локально. Сервер принимает remote schema2 только при соответствии сохранённой start/retry-команде нужного kind, эпохе, источнику и fingerprint; cancel не является основанием нового запуска. При смене эпохи/паузе незавершённые фазы становятся interrupted. TTL команды 5 минут, лимиты 2worker/256nodes/45min и публичного отчёта прежние. Старые retry/cancel не управляют schema2.

Проверки синтетические; не включать реальные MDM/VPN/радио и не развёртывать сервер. Физические LTE/OEM/батарея не считаются пройденными.
