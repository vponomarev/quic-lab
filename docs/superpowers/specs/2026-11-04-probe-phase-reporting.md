# Двухсетевые результаты диагностики в MDM

Продолжение принятой архитектуры adaptive paths от 2026-10-23, база b6749a3. Пользователь поручил автономно закрывать группы задач; исполнитель сохраняет Kotlin/Go и существующий worktree.

Локальный пробинг уже хранит schema=2 с phases wifi/cell, но MDM его исключает. Добавляем capability vless_probe_phases_v2 для отчётов. Старый сервер получает только прежние schema=1; новый получает последний допустимый результат с обеими фазами. Команды MDM остаются одно-сетевыми: расширение отчёта не расширяет полномочия запуска.

Варианты: проецировать только последнюю фазу в v1 (теряет предыдущую сеть); отдельный endpoint/хранилище (дублирует права и freshness); расширить ProbeSnapshot опциональными schema/phases (выбран исполнителем, сохраняет единое хранилище и проверку прав). Для schema=2 верхние rows отсутствуют, network указывает текущую фазу или none до её начала. Фазы содержат только network/state/reason/rows/startedAt/finishedAt, без приватной metadata. Неизвестные схемы не отправляются. Публичные строки копируются по разрешённым полям, а не вместе с возможными credentials. Предел снимка 768 КиБ, существующий предел report/request 1 МиБ не увеличивается; если снимок вместе с отчётом превышает 900 КиБ, он не прикладывается, базовый отчёт продолжает работу.

Сервер проверяет capability, права VPN+telemetry, source/fingerprint, monotonic sequence, 1–2 уникальные физические сети, максимум 256 строк на фазу, ограниченные состояния/причины, совпадение состава узлов между фазами. Пропуски no_network/permission_denied/budget нейтральны; не допускают success. Старые результаты и управление остаются совместимыми. Админка позволяет выбрать фазу, показывает её состояние/причину и строки; локальные двухсетевые запуски нельзя отменять или повторять через старую MDM-команду.

Проверки: нативные RED/GREEN и full Linux suite, Android synthetic instrumentation на Note9, исполняемый DOM-тест панели. Не использовать реальные подписки/согласия/радиопереключения или production. Не объявлять физическую LTE/Doze приёмку выполненной.
