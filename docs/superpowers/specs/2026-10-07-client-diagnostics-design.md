# Диагностика клиента и доставка — согласованный дизайн
2026-10-07. Пользователь согласовал реализацию и тестовый Redmi.
- Настройка сбор+автоотправка включена по умолчанию ближайшего релиза; явный выбор сохраняется. Выключение прекращает сбор/автоотправку, накопленное можно отправить или удалить.
- События 7 дней/5 MiB, сводки каждые 30 секунд 3 дня/10 MiB, подробные потоки отдельный opt-in 24 часа/20 MiB. Истекает первый лимит. Без payload, секретов и геоданных.
- Автоотправка каждые 5 минут только validated NOT_METERED Wi-Fi; ошибки запускают раннюю попытку с backoff. Вручную все накопленное через выбранную физическую сеть, включая LTE; политику не меняет.
- HTTPS по origin проверенного config_url, без redirect, device update bearer из encrypted identity. Привязка очереди к профилю/серверу; никакого угадывания адреса из стороннего VLESS/AWG endpoint.
- Подтверждение только после durable write, повтор не дублирует batch. Ограничения на wire/decompressed body и запись. Клиент сохраняет локальную историю после ACK до retention.
- Сервер: 14 дней, общий лимит 500 MiB по умолчанию (настраивается); закрытая админская временная шкала с timestamp клиента и временем приёма. События сервера сопоставляются по устройству/времени, без раскрытия чужих журналов публичному API.
- UI: явный статус включения, адрес получателя, последняя доставка, размер очереди, отправить/удалить, отдельный detailed switch.
- Старые профили без device update token сохраняют локальные журналы; показывают отсутствие адреса доставки.
- Не заявлять исправление дорожного зависания QUIC: функция собирает доказательства.
