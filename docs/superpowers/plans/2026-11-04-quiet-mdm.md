**Architecture:** JobScheduler + persistent local choice; existing controller/transport/consent owners; exclusive session lease shared by foreground and job workers. Capability-gated reported mode.
**Tech Stack:** Kotlin Android API30+, Go MDM; existing dependencies only.
**Spec:** ../specs/2026-11-04-quiet-mdm-design.md and POST-P1-06.

## Global Constraints
- Base89be9d5, reuse phase1-vpn worktree. No unrelated dirty cell/admin/server files in commit.

- No real user VPN/MDM/radio state changes; no production deploy/push.
- Pause, generation, consent, Wi-Fi-only and LTE budget remain authoritative.
- No claim of measured battery improvement or full OEM acceptance.

## Review Focus
- Canceled session must drain before a successor can own shared controller cancellation.
- Process recreation, boot and screen changes must not start foreground services in quiet mode or duplicate jobs.
- Switching mode or VPN state must stop the obsolete collector while retaining consent and queued data.
- Job cancellation between phases must prevent further reports/commands and release all ownership.
- Old servers must never receive unsupported status fields; applied status stays distinct from desired.
