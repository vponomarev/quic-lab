# v0.8.0-pre.5 — состояние VLESS на основном экране

Android versionCode 25. На карточке VLESS-выхода и в состоянии сервиса отображаются две независимые строки:

- TCP до сервера: подключение / установлен / закрыт / ошибка подключения.
- Передача через VPN: проверяется / подтверждена / проверка не прошла / нет свежего подтверждения.

TCP определяется наличием открытых физических сокетов к серверу, с обновлением раз в секунду. Один профиль может иметь несколько таких сокетов; закрытие одного не означает закрытие остальных. TCP не является подтверждением авторизации VLESS. В отсутствие запросов открытых TCP-соединений может не быть даже после успешной проверки VPN.

Передачу подтверждает существующая проверка HTTPS через туннель. Отрицательный результат означает отказ проверки, а не доказанный отказ всех назначений. Подтверждение сбрасывается при переподключении, не переносится из старого поколения и устаревает через 30 секунд. Проверка действует и при выключенном RTT.

Исправлены преждевременное «Туннель подключён» при создании движка и ошибочное сообщение AmneziaWG/ICMP при отказе проверки VLESS. Протокол, настройки профиля и алгоритм переключения сетей не изменены.

Проверки: Linux full go test/vet PASS (mobile 53.791 s), targeted VLESS race PASS; Android build/lint PASS; 31 тест PASS (6.529 s). Отдельный live-тест текущего пользовательского VLESS-профиля подтвердил ответ туннеля и корректный lifecycle уведомления. RED → GREEN покрывает отдельный TCP-статус, отсутствие преждевременного успеха, работу без RTT, истечение подтверждения и старое поколение.

Открытая проверка: внешний тестовый REALITY/Vision-профиль проходит TCP/UDP на Wi-Fi, но HTTPS из тестового приложения после перехода на LTE завершился таймаутом/закрытием TLS в двух запусках. Проверка туннеля при этом получает ответ. Тот же таймаут воспроизведён на опубликованном pre.4 при сравнении без изменения профиля. Причина пока не установлена; полный сценарий Wi-Fi → LTE → Wi-Fi не объявляется пройденным в этом выпуске. Временный профиль удалён, исходный профиль и Wi-Fi восстановлены; после контрольного отката на телефон возвращён pre.5.
