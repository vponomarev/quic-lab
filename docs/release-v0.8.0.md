# v0.8.0 — промежуточная фаза 1″

Владелец 2026-10-04 утвердил выпуск текущего состояния отдельным промежуточным checkpoint. Полная фаза 1 остаётся открытой; её оставшиеся критерии не считаются выполненными из-за номера 0.8.0. MDM отложен до полного закрытия стадий VPN-сервера.

Android versionCode33, Android11+/ARM64 и x86_64. Сохранена прежняя подпись sideload APK для обновления без удаления профилей.

## Состав

Android VPN с QUIC/HTTPS/AmneziaWG/VLESS, независимые выходы, маршрутизация приложений/IP, общий LTE-бюджет, диагностика и обновление профилей. Сервер Linux с systemd, единым TCP/UDP443, SNI-разделением web/mTLS/VLESS, отдельным AWG-портом, ACME и ручными настройками. Управление пользователями/устройствами, QR/ссылками подключения, VLESS TLS/REALITY и расширенными параметрами входа.

Включены исправления reconnect QUIC/HTTPS, restart policy службы, подсказка фоновых разрешений MIUI и открытие экрана VPN из уведомления. При обновлении сервера существующие сессии могут прерваться; обновлять сервер и клиент согласованно.

## Ограничения checkpoint

- IPv4; IPv6 и доменная маршрутизация не включены в завершённый объём.
- На проверенных MIUI режим «все приложения» может рвать TCP при возврате Wi-Fi; выбранные приложения — проверенный обход. POST-P1-01 сохраняется.
- Строгая защита от обхода исключения приложения через прямую привязку к TUN отложена во вторую фазу (POST-P1-02).
- Очистка MIUI требует разрешения фонового автозапуска; при разрешении повторный OneKeyClean на тестовом Redmi сохранил VPN. Универсальное восстановление после crash процесса не подтверждено: shell-induced crash на Redmi пока не восстанавливает службу. START_STICKY не обещает обход ограничений ОС/force-stop. Полный перезапуск службы начинает новый период LTE-бюджета.
- Полная физическая матрица B4/E2, сетевые fault/load проверки E5, 15 активных/≥30 допущенных устройств и цель100Мбит/с остаются за полной фазой1. Это не заявленные результаты нагрузочного теста.
- Полная live-матрица расширенных VLESS TLS/REALITY настроек с нашим клиентом/HAPP остаётся открытой.

## Артефакты

`quic-lab-0.8.0.apk`, Linux amd64/arm64 архивы сервера с workers/установщиками/документацией/лицензиями, исходники тега v0.8.0, SHA256SUMS и отчёт о регрессии. ARM64 сервера cross-built; runtime-проверки на amd64. Ключи подписи, production-конфиги, учётные данные и необработанные журналы личного телефона в публичный релиз не входят.
