# QUIC Lab 0.9.5-pre.16

Предварительный релиз от 16 ноября 2026 года.

## Исправление Android

Исправлено зависание Telegram в состоянии «Ожидание сети…» после отключения
Wi-Fi и перехода на LTE. VPN своевременно сообщает Android доступность основной
сети, независимо от завершения миграции транспорта. Успешный переход сохраняет
QUIC-сессию, TUN и открытые TCP-потоки. Краткая потеря обеих сетей также проверена.

Исправлено объединение сведений о сетях нескольких выходов и различие между
временной потерей каналов и намеренной паузой. На Note12 проверен обычный QUIC;
для нескольких каналов выполнены ревью и регрессионные проверки логики.
Длительный обрыв с истечением тайм-аута QUIC по-прежнему требует новых TCP-потоков.

## Файлы

| Компонент | Файл |
| --- | --- |
| Android 11+, arm64-v8a / x86_64, код 81 | `quic-lab-0.9.5-pre.16.apk` |
| Linux-клиент x86_64, Go GUI | `quic-lab-client-0.9.5-pre.16-linux-amd64.tar.gz` |
| Windows-клиент x64, .NET включён | `quic-lab-windows-0.9.5-pre.16-x64-setup.exe` |
| Linux-сервер amd64 | `quic-lab-server-0.9.5-pre.16-linux-amd64.tar.gz` |

Linux/Windows и сервер собраны из общего тега; функциональных изменений в них
относительно pre.15 нет. Серверные архивы содержат все четыре исполняемых файла.
Linux GUI требует systemd, glibc >= 2.38 и OpenGL/X11/XWayland; Python не нужен.

Android подписан прежним сертификатом preview-сборок и обновляет pre.13, pre.15
и тестовую pre.16-dev без удаления данных. APK debug, вне Google Play.
Установщик Windows не подписан; подпись включённого Wintun проверяется при сборке.
Контрольные суммы: `SHA256SUMS.txt`; происхождение файлов: `release-manifest.json`.
