# QUIC Lab Windows 0.1.0-beta.3

Исправлены переключение транспорта после импорта и лишние операции при подключении Windows-клиента.

## Установка

Скачайте `quic-lab-windows-0.1.0-beta.3-x64-setup.exe`, закройте окно QUIC Lab и запустите установщик. Он обновляет существующую установку Windows 10/11 x64 и сохраняет профиль. После обновления VPN выключен; откройте QUIC Lab из меню «Пуск» и подключитесь.

## Что исправлено

- Оба списка транспорта согласованы: выбор AWG подставляет его профиль и адрес, а не оставляет ключ QUIC. Маршрутизация и выбор физического адаптера сохраняются.
- Загруженные альтернативные профили доступны до закрытия редактора, в том числе после сохранения. Сохранённые правки ключей не теряются при переключении, даже если переподключение после сохранения не удалось.
- Если выбранного транспорта нет в загруженном наборе, редактор просит импортировать его профиль. Неподдерживаемый AWG/VLESS-профиль больше не сопровождается общей подсказкой о сертификате.
- Автоматическое подключение использует один снимок физической сети на попытку запуска. Сведения об адаптерах, адресах и маршрутах читаются пакетно.
- Проверка маршрутов использует один снимок всей таблицы с сохранением отказа при конфликтующих маршрутах. Очистка устаревших DNS-правил и установка своего правила выполняются одним запуском PowerShell.

## Проверки и ограничения

Регрессии WPF покрывают QUIC → AWG → HTTPS, сохранение и повторный выбор, отсутствие профиля и сохранение при неудачном переподключении. Go-тесты проверяют выбор адаптера, отсутствие повторного обнаружения, проверку маршрутов, DNS-владение, отмену и восстановление сети.

На тестовом Windows-компьютере среднее чтение параметров сети в трёх итерациях: beta.2 — 2,07 с, beta.3 — 1,80 с. При запуске эта операция теперь выполняется один раз вместо двух; дополнительно сокращены проверки маршрутов и запуск PowerShell для DNS. Это замер компонента, а не полного подключения: время AWG 1–2 с на другом ноутбуке пока не подтверждено. Статус готовности не показывается раньше завершения настройки сети.

Остаются ограничения beta: IPv4, без kill switch и маршрутизации по приложениям; один сохранённый профиль. Полный цикл обновления с UAC и живое подключение новой сборки на чистом ноутбуке не проверены. Установщик и приложение пока без Authenticode-подписи; Wintun подписан WireGuard.
