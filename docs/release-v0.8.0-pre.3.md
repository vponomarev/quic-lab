# v0.8.0-pre.3 — Android standalone VLESS

Промежуточный клиентский выпуск, Android versionCode 23. APK подписан прежним debug-ключом и обновляется поверх предыдущей версии с сохранением профилей. Android 11+, ARM64 / x86-64.

## Подключение к существующему VLESS-серверу

Остановите VPN. В настройках VPN выберите «Сканировать QR» для QR с отдельной ссылкой `vless://`, либо «Импортировать VLESS URI / JSON» для вставки текста. Импорт из файла доступен через «Импортировать профиль .json / .conf». Проверьте адрес и тип защиты в диалоге, подтвердите импорт, выберите приложения и включите VPN.

Поддерживаются TCP/RAW + TLS или REALITY, включая Vision. JSON — один VLESS outbound, не полный конфиг Xray. QR может содержать VLESS URI либо такой outbound. Импорт не требует сервера QUIC Lab или регистрации устройства на нём. Данные доступа хранятся зашифрованно.

URI должен содержать явные `security` и `sni`; допустимые параметры: `encryption`, `security`, `type`, `sni`, `fp`, `flow`, `pbk`, `sid`. Неизвестные поля и неподдерживаемые сочетания отклоняются. Экспорт из сторонней панели может потребовать настройки под эту ограниченную матрицу; совместимость с любым QR 3x-ui не заявляется.

## Что входит

- Standalone VLESS TCP/UDP через встроенный Xray-core; переходы Wi-Fi/LTE, диагностика выхода и общий бюджет мобильного трафика.
- Накопленные клиентские изменения после pre.2: учёт и ограничения LTE, раздельная политика системного/туннельного DNS, обновление конфигурации устройств и диагностика выходов. Серверные возможности требуют соответствующей версии backend.
- Исходники серверных доработок присутствуют в теге, но серверные бинарники этого выпуска не публикуются и действующий сервер не обновляется. Для standalone VLESS обновление сервера QUIC Lab не требуется.

## Ограничения

- Смена физической сети пересоздаёт standalone VLESS-соединения: приложения могут переподключаться. VLESS через общую demux-сессию, пул одинаковых соединений, карусель VLESS и управляемый VLESS-сервер пока не поставляются.
- WS, gRPC, XHTTP, подписки и полный Xray JSON не поддерживаются. Только IPv4.
- Сохраняются upstream-ограничения remote EOF/half-close, UDP до 8190 байт и Vision UDP/443. Подробнее: [матрица совместимости](https://github.com/vponomarev/quic-lab/blob/v0.8.0-pre.3/docs/vless-compatibility.md).
- Проверки доступности используют HTTPS к api.ipify.org; показываемая задержка включает весь путь до этого сервиса.
- Ограничение Android/MIUI для режима всех приложений и незавершённые длительные/нагрузочные проверки первой фазы сохраняются. Для личного использования рекомендуется проверенный режим выбранных приложений.
