# 0.8.1-pre.2 — обновление профиля по регистрационному QR

Android versionCode 35. Сервер совместим с 0.8.1-pre.1 и не изменён.

После получения регистрационного VPN-профиля доступны «Обновить…» и «Добавить новое».
При обновлении пользователь явно выбирает существующее подключение; совпадение имени или сервера
само по себе не заменяет профиль. Обновление требует остановленного VPN.

Сохраняются ID и имя подключения, текущий выбор профиля, приложения, маршруты, режим работы,
бюджеты и настройки каналов. Серверные адреса, DNS, протоколы и ключи обновляются.
Выбранный транспорт сохраняется, если сервер продолжает его поддерживать.
Ключи и серверные настройки проверяются до единственной атомарной записи зашифрованного файла.
Некорректный импорт оставляет старую конфигурацию без изменений.

Сценарий рассчитан на регистрационный QR/ссылку QUIC Lab с данными устройства.
Повторная регистрация может создавать новое устройство на сервере, хотя локальный профиль остаётся прежним.
Для последующих обновлений используйте «Обновить конфигурацию с сервера» в редакторе профиля.

Старые диагностические записи с прежним адресом доставки не перенаправляются на новую регистрацию.
История без адреса доставки остаётся локальной; новые записи получают адрес зарегистрированного устройства.

Проверка: Android build и lint PASS; полный обычный instrumentation-прогон OK (133 tests), opt-in сценарии отдельно не включались. Новые тесты подтверждают замену без дубля, сохранение локальных параметров, переход с legacy-профиля и отсутствие изменений при некорректном импорте.
