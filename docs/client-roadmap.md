# План клиентов: Android, Windows и Linux

Актуализация 2026-11-04. Это сводка текущего кода и подтверждённых проверок; старые unchecked пункты не означают автоматически, что функции отсутствуют. Приоритет следующей разработки — desktop-паритет, особенно Windows; Android продолжает получать исправления общего ядра и физическую приёмку. Реализация, испытание на устройстве и публикация учитываются отдельно.

## Порядок следующих пакетов

1. **Общее ядро + Linux/Windows транспортный паритет — реализовано.** [План](superpowers/plans/2026-11-04-desktop-transport-parity.md): Linux AWG/VLESS, сохранение WebSocket в общем шлюзе, корректное объединение Windows AWG AllowedIPs. [Проверки и ограничение REALITY checkptr](testing/desktop-transport-parity-2026-11-04.md).
2. **Windows: маршрутизация приложений.** Реализовать OwnerResolver/FlowRouter/direct по [принятому дизайну](superpowers/specs/2026-10-14-windows-per-app-tun-design.md), затем подключить существующий редактор списков к службе. Черновой список exe сам по себе маршрутизацию не включает. TCP/UDP ownership, PID reuse, неизвестный владелец, смена политики и сети требуют отдельных тестов. Прежний WFP-план заменён, новый драйвер не является условием этого варианта.
3. **Windows: библиотека профилей и независимые выходы.** Безопасно сохранять несколько импортированных профилей, выбирать активный, обновлять/откатывать без потери маршрутизации; затем маршрутизировать по ExitID. Сейчас сохранён один профиль, альтернативы импортированного набора живут в редакторе.
4. **Linux: жизненный цикл.** Проверяемая готовность AWG/VLESS, ограниченные повторные подключения, обработка смены физического интерфейса и systemd. Открытый локальный движок не доказывает доступность удалённого сервера.
5. **Android и общий выпуск.** Физическая приёмка накопленных групп/MDM, затем версии и публикация соответствующих компонентов. Синтетические тесты и debug APK не закрывают физические пункты.

Полный kill switch/IPv6-изоляция — отдельное развитие с системной приёмкой. Принятый Windows per-app дизайн управляет IPv4 через TUN/direct, не обещает kernel-изоляцию выбранных приложений при аварии процесса. Linux preview также не имеет kill switch и не меняет системный DNS/IPv6.
