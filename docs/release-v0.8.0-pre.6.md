# v0.8.0-pre.6 — единый порт и управляемый VLESS

Android versionCode 26. Сервер и APK развёрнуты на quic-demo.vpnc.ru; завершающие live-проверки и публикация GitHub ещё выполняются.

Новая установка использует TCP/443 для HTTPS/mTLS, Web UI и VLESS с отдельными SNI; UDP/443 объединяет QUIC VPN и echo. Для VPN обязателен клиентский сертификат, включая предложение нескольких ALPN. Сохраняется ручная конфигурация отдельных портов. Параметр `public_tls_min` сохраняет возможность TLS 1.0 для Web UI через корпоративный прокси даже на общем порту. VPN-маршруты HTTPS всегда требуют TLS 1.3 и проверенный клиентский сертификат. AmneziaWG остаётся на отдельном UDP-порту.

Собственный VLESS worker поддерживает TLS и REALITY/Vision, профили и QR устройства, динамическое применение и отзыв доступа. Android импортирует управляемые VLESS-профили и обновляет их с сохранением локальных настроек. Исходный IP:порт передаётся worker через PROXY v2; принимающий listener доступен только на loopback. В админке появились активные VLESS-соединения с исходными адресами; сведения истекают за время аренды допуска (до 2 секунд), счётчики трафика VLESS пока не собираются.

Установщик получает сертификат ACME для нескольких имён, настраивает автоматическое продление и поддерживает ручные сертификаты. Существующая установка сохраняет порты до явной миграции. После миграции старые профили с прежними портами нужно обновить.

Проверено до развёртывания: полный Linux Go test/vet, целевые race-проверки; Android assemble/lint; прогон 17 тестов импорта/совместимости (опциональный тест внешнего QR без входной фикстуры не выполнял сетевой импорт). В race-проверках сохраняется документированное исключение checkptr для unsafe-кода Vision в закреплённой upstream-версии Xray.

Границы выпуска: подписки и мультиплексирование через внешние VLESS ещё не включены. Прежнее ограничение Android в режиме «все приложения» и отдельный открытый кейс стороннего REALITY-провайдера при переходе на LTE остаются в плане. Прохождение live-проверок и ссылки на артефакты фиксируются после развёртывания.

Исправлена совместимость запуска под systemd DynamicUser: поддерживаются служебная ссылка StateDirectory и root-owned credential-файлы с правами 0440 и адресным ACL. Проверки приватности обычных ключей и каталога допуска сохранены. На production проверены публичный Web UI по TLS 1.0, echo через UDP/443, наличие обоих SAN и совпадение SHA256 APK с установленной сборкой. Штатное повторное обновление установщиком прошло успешно.
