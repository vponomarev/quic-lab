# v0.8.0-pre.6 — единый порт и управляемый VLESS

Android versionCode 26. Сервер обновлён на quic-demo.vpnc.ru, APK опубликован и установлен на тестовом телефоне.

TCP/443 объединяет HTTPS/mTLS, Web UI и VLESS с разными SNI; UDP/443 объединяет QUIC VPN и echo. Для VPN обязателен клиентский сертификат, включая смешанные предложения ALPN. VLESS использует ui.quic-demo.vpnc.ru. AmneziaWG остаётся на отдельном UDP-порту. Раздельные порты и ручная настройка сохраняются.

Параметр `public_tls_min` позволяет оставить TLS 1.0 для Web UI через корпоративный прокси на общем порту. Оба HTTPS VPN-маршрута независимо требуют TLS 1.3 и проверенный клиентский сертификат. Установщик сохраняет эту настройку при миграции.

Собственный VLESS worker поддерживает TLS и REALITY/Vision, профили и QR устройства, динамическое применение и отзыв доступа. Android импортирует управляемые профили и обновляет их с сохранением локальных настроек. PROXY v2 передаёт исходный IP:порт клиента на приватный loopback backend. Админка показывает активность VLESS с исходными адресами; сведения истекают в пределах аренды допуска (до 2 секунд). Счётчики трафика VLESS пока не собираются.

Установщик получает сертификат ACME для нескольких имён и настраивает продление. Поддерживаются ручные сертификаты. Исправлена совместимость с systemd DynamicUser: служебная ссылка StateDirectory и root-owned credential-файлы с адресным ACL. Проверки приватности обычных ключей и каталога допуска сохранены.

Проверено:

- Полный Linux `go test ./...` и `go vet ./...`, целевые race-проверки, 56 тестов установщика. Для unsafe-кода Vision закреплённой версии Xray сохранено документированное исключение checkptr.
- Android assemble/lint и 17 тестов импорта/совместимости. Опциональный тест внешнего QR без фикстуры не выполнял сетевой импорт.
- Production: QUIC/mTLS и HTTPS/mTLS с передачей HTTPS-трафика через общий порт; VLESS TCP/HTTPS и UDP/DNS; исходный IP:порт в админке; отказ подключения после отзыва тестового аккаунта.
- Телефон: VLESS TCP/UDP на Wi-Fi, после перехода на LTE и после возвращения на Wi-Fi. Временный профиль удалён, прежний выбор восстановлен, VPN после теста выключен.
- Публичный Web UI через TLS 1.0, echo через UDP/443, SAN обоих доменов и успешное пробное продление ACME. Публичный APK совпадает по SHA256 с релизным файлом.

После перехода сервера на общий порт **обновите или повторно импортируйте профили** с прежними портами. Обновление сервера прерывает активные подключения.

Подписки и мультиплексирование через внешние VLESS ещё не включены. Прежнее ограничение Android в режиме «все приложения» и отдельный открытый кейс стороннего REALITY-провайдера при переходе на LTE остаются в плане. Нагрузочная проверка на 512 устройств в этот выпуск не входила.

[Скачать APK с сервера](https://quic-demo.vpnc.ru/lab/download/quic-lab.apk)

Уточнение для обновления существующего сервера с AWG: установщик из архивов pre.6 требует явный `--enable-awg`, чтобы обновить ранее установленный AWG worker. Иначе старый worker может не поддерживать подтверждение сохранения доступа (`AWG worker reload unavailable`). В ветке разработки обновление включённого AWG выполняется автоматически. На quic-demo.vpnc.ru worker уже обновлён; сохранение протоколов через админку проверено.
